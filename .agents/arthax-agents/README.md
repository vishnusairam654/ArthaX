# ARTHAX Agent Pack — Frontend & Design Slice

These six agents are the initial ARTHAX working team. They are designed to work with the existing ARTHAX skills rather than duplicate them.

## Agents

1. `arthax-director.md` — orchestrates tasks, selects skills/agents, controls scope, and approves handoffs.
2. `arthax-frontend-builder.md` — implements Next.js UI, pages, components, states, and integration.
3. `arthax-visual-director.md` — makes visual/design decisions using the canonical ARTHAX design system.
4. `arthax-motion-agent.md` — owns motion implementation and choreography using GSAP/Motion rules.
5. `arthax-asset-agent.md` — owns existing asset intake, mapping, sizing, naming, and prevents fabricated replacements.
6. `arthax-design-auditor.md` — audits finished UI for anti-AI signals, design-system violations, accessibility, responsive issues, state depth, and motion problems.

## Working rule

Director -> plan/route -> Visual + Asset guidance -> Frontend implementation -> Motion pass -> Design audit -> fix/re-audit.

Do not create backend/financial agents in this pack yet; those are intended for the backend/ledger phases.
